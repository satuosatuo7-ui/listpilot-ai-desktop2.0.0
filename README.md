GitHub Actions 的额度和费用由你的 GitHub 套餐决定；没有购买任何服务。

## 不写代码：使用 GitHub 自动构建

1. 下载交付 ZIP，解压。
2. 在 GitHub 点 **New repository**，仓库名可填 `listpilot-desktop`，建议 Private；勾选创建 README，以便出现上传入口。
3. 打开仓库，点 **Add file → Upload files**。
4. 上传解压目录**里面的文件和文件夹**：`package.json`、`package-lock.json`、`electron`、`build`、`test`、`README.md`、`AGENTS.md` 等。它们必须位于仓库根目录，而不是再套一个 `desktop/windows` 或 `ListPilot-AI-Windows` 文件夹。
5. `.github` 是隐藏目录，某些文件管理器或网页上传会漏掉。请打开显示隐藏文件后一起上传；同时确认仓库中存在 **`.github/workflows/windows.yml`**。
6. 如果 `.github` 上传失败：在仓库点 **Add file → Create new file**，文件名填写 `.github/workflows/windows.yml`，把 ZIP 中同名文件的完整内容复制进去，点 **Commit changes**。这是复制现成文件，不需要编写代码。`.gitignore` 可用同样方式补齐。
7. 点 **Actions**，如出现提示，允许启用该仓库的工作流。
8. 选择 **Build Windows installer → Run workflow → Run workflow**。
9. 等待任务结束。构建阶段会自动安装依赖、运行安全测试、生成 NSIS EXE、计算 SHA-256，然后上传安装包，再检查打包后的程序能否打开真实登录页。
10. 打开该次运行，向下找到 **Artifacts**，下载 **ListPilot-AI-Windows-x64**。
11. 解压下载的压缩包，得到 **`ListPilot-AI-Setup-1.0.1-x64.exe`** 和 `SHA256SUMS.txt`。

安装包在本项目的 `release/` 中生成；Actions 里的下载附件默认保留 30 天。可再次运行构建重新生成。网站源文件不需要上传到这个仓库。

如果运行显示红色：先看是否仍有安装包附件。启动检查是在上传安装包之后执行，网站临时网络故障可能导致启动检查失败；**有 EXE 不代表已通过测试**，需要查看失败步骤并重新运行。不要通过关闭 sandbox、TLS 校验或系统防护来修复。

## 如何连接现有网站

**已经连接好了，无需填写密钥**：`electron/config.cjs` 指向 `https://linze.lovable.app/`。

客户端启动直接加载线上网页，不打包网站静态文件，因此不需要改网站 Vite 设置或重新部署网站。线上网站未发布的预览改动不会出现在桌面端。

只有将来更换官方域名时，才需要同时更新该文件中的 `websiteUrl` 和 `officialOrigin`，运行测试并重新生成客户端安装包。不要允许任意 `*.lovable.app` 域名。

## 登录、数据和权限

- 直接使用现有网站的邮箱和密码；卡密仍只是原有积分充值方式，不是登录方式。
- 网页与桌面访问同一个 Lovable Cloud，服务端授权判断、积分和商品数据沿用原有规则，没有新增会员制度。
- 桌面会保留自己的登录存储，退出软件再打开通常不需要重新登录；过期、撤销会话或主动退出登录后，需要按原网站规则重新登录。
- 桌面与系统浏览器不共享登录 Cookie：第一次启动桌面通常要登录一次。
- 原有设备绑定仍生效，桌面可能被计为新的设备；不会绕过现有设备限制。
- 外部链接交给系统默认浏览器；第三方网站不会在桌面窗口里打开。网页登录确认/重置邮件在系统浏览器打开时，桌面可回到登录页面用邮箱密码登录。
- 默认卸载保留客户端登录缓存以便重装；在共享电脑上应先退出账号。需要彻底清理时，关闭程序后删除 `%APPDATA%\ListPilot AI`（请先确认该目录归属，不要删除其他软件目录）。

## Windows 安装和测试清单

1. 双击 EXE，选择安装目录，完成安装；桌面、开始菜单出现 ListPilot AI 图标。
2. 启动后确认显示真实网站登录页，不是空白窗口。
3. 使用现有邮箱密码登录，打开商品管理，检查是否是网页版同一批商品。
4. 比较网页和桌面的积分余额；在桌面修改一项允许修改的数据，在网页刷新后确认同步。
5. 关闭并重新启动桌面，确认登录状态和数据保持；然后退出账号，再确认重新进入需要登录。
6. 测试上传/粘贴图片、复制文案、下载单张图片及勾选图片 ZIP。保存文件应出现系统保存对话框。
7. 点击 Vinted 等外部链接，确认进入默认浏览器而不是桌面窗口；原浏览器工具中的外部嵌入页面在桌面端可能被阻止，这是指定域名限制，不是新增代理。
8. 断网后启动，检查可操作的重新加载提示；联网后点重新加载。
9. 网站发布一次可识别的文字更新后，在桌面选 **ListPilot AI → 重新加载网站**，确认最新文字；安装包版本不会随网站变化。
10. 在 Windows **设置 → 应用 → 已安装的应用** 找到 ListPilot AI 并卸载，检查快捷方式被移除；重装测试。
11. 重新添加采集书签，在有权使用的商品页勾选主图并确认：软件关闭时应启动并保留采集内容，已运行时应切换到同一窗口；未登录时先按原规则登录，登录后继续确认采集。检查采集记录及图片保存，积分不变。

不要为了验收而触发付费生图；如果你确实点击付费生成，仍按网站原有成功后扣积分规则执行。

## 安全实现

- `contextIsolation: true`、`sandbox: true`、全局 `app.enableSandbox()`；关闭所有 renderer/worker/subframe Node integration。
- 不提供 preload、本地文件/命令 IPC、任意 shell 执行入口，不禁用 TLS 校验或 webSecurity。
- 顶层导航、重定向、子框架导航均只信任精确官方 HTTPS 域名，禁止网页创建额外 Electron 窗口或 webview。
- 外部链接只接受安全的 HTTP/HTTPS/mailto 类型，禁止本地文件、javascript、自定义系统命令协议。
- 默认拒绝设备/摄像头/麦克风权限，仅允许官方页面写入普通剪贴板以支持现有复制按钮；不允许自动读取剪贴板。
- 文件下载由系统保存对话框决定位置，网页不能指定本地任意路径；支持官方页面生成的 blob ZIP 与正常 HTTPS 图片下载。
- 安装包只包含桌面壳及图标，不包含 `.env`、网站源码或 API/数据库私密密钥。网站正常发送给浏览器的公共配置仍像网页版一样由线上网页加载。

## 网站更新和客户端更新：两回事

**网站业务更新**：网站正常发布后，客户端重开或菜单重新加载会读取最新网页，沿用现有账号登录存储。

**客户端版本更新**：修改桌面壳时需要新的 EXE；当前自动更新**未启用**。`electron/updates.cjs` 是后续扩展位置，菜单明确显示当前版本和更新状态。现在下载新 EXE 覆盖安装。

将来启用真正的客户端自动更新，需要配置可靠的 HTTPS 发布源、版本元数据、签名、用户确认/失败回退策略，再添加 electron-updater；不能将网站刷新称作自动升级 EXE，也不要直接信任未签名的测试构建附件。

## 给维护者的文件索引

- `electron/config.cjs`：公开官网地址、独立持久会话、更新预留配置。
- `electron/main.cjs`：窗口、安全策略应用、系统浏览器、下载和错误提示。
- `electron/policy.cjs`：可单元测试的域名/协议/权限规则。
- `electron/updates.cjs`：独立客户端更新扩展位置，目前只显示状态。
- `build/icon.ico`、`build/icon.png`：沿用网站现有图标。
- `package.json`：Electron Builder/NSIS 配置。
- `package-lock.json`：固定依赖版本。
- `.github/workflows/windows.yml`：Windows 自动构建、附件和启动检查。
- `test/policy.test.cjs`：安全及安装配置测试。
- `test/windows-smoke.cjs`：Windows 打包程序启动、登录页、隔离检查；不操作真实账号。
